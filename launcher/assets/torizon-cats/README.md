# User-selected animated mascots

The user supplied `boykisser.gif` and `mauzymice-mauzy.gif` on 6 November 2026,
and requested programmatic removal of the white background without changing the
original frames or playback speed. The artwork was not generated by Torizon.

- `wave.gif`: boykisser.gif, 498 x 374, 132 frames, 4.41-second infinite loop.
- `wink.gif`: mauzymice-mauzy.gif, 498 x 373, 10 frames, 1.2-second infinite loop.
- Matching PNGs contain the first transparent frame for the paused state.

The import tool preserves white fur enclosed by the ink contour, removes the
edge-connected background, and checks every frame's timing and transparency.
Every frame uses full disposal to prevent trails. Repeated frames are retained.
The launcher preserves the original aspect ratios and pauses animations during gameplay.

Development import (requires Pillow, NumPy and OpenCV):

```
python tools/import_torizon_mascots.py --wave /path/to/boykisser.gif --wink /path/to/mauzymice-mauzy.gif
```

The player's launcher embeds the processed GIFs and requires no Python tooling.
